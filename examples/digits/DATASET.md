The included test.csv is the original optdigits.tes from E. Alpaydin and C. Kaynak,
Optical Recognition of Handwritten Digits (1998), UCI Machine Learning Repository.

[Dataset and citation](https://doi.org/10.24432/C50P49) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The model trains on 3,823 examples and evaluates the separate 1,797-example test
split. Each image has 64 pixel values (8 x 8, values 0-16). Inputs are divided by 16.
